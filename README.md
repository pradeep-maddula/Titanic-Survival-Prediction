# Titanic Survival Prediction 🚢

## Project Overview
This project predicts passenger survival during the Titanic disaster using Machine Learning classification algorithms.

The goal is to analyze passenger information and build models to predict whether a passenger survived or not.

## 📂 Dataset
- `train.csv` – Training dataset
- `test.csv` – Testing dataset
- `submission.csv` – Final predictions

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

## ⚙️ Project Workflow
1. Data Loading
2. Exploratory Data Analysis
3. Data Preprocessing
4. Handling Missing Values
5. Categorical Encoding
6. Feature Selection
7. Model Training
8. Model Evaluation
9. Survival Prediction

## 📊 Model Evaluation
Models are evaluated using accuracy and classification metrics.
